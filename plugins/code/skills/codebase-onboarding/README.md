# Codebase Onboarding skill

Generates a fresh, guided onboarding course for a new developer joining this codebase — setup, architecture, testing, patterns, and frameworks — as short interactive lessons with quizzes. Rerun any time for an up-to-date snapshot instead of maintaining stale docs.

State lives in `.onboarding-docs/` inside the repo — add that path to your `.gitignore` (the skill won't do it for you). Every run fully regenerates the course from the codebase's current state.
